# Вітальна листівка

Складная бумажная открытка-сайт. Клик по открытке, и она подлетает и раскрывается. Стих «пишется» сам,
свайп справа налево перелистывает страницу. На последней странице прорисовывается цветок.

Обычный статический сайт: HTML, CSS и JavaScript, без сборки и без зависимостей.
Открывается двойным кликом по `index.html`.

---

## Публикация на GitHub Pages

Пути в проекте относительные, поэтому сайт работает и по адресу вида `https://логин.github.io/репозиторий/`.

### Вариант А. Через сайт GitHub (без командной строки)

1. Зайдите на https://github.com/new, придумайте имя (например, `oksana-card`), выберите **Public**, нажмите **Create repository**.
   Для бесплатного аккаунта GitHub Pages работает только с публичными репозиториями.
2. На странице нового репозитория нажмите **uploading an existing file**.
3. Перетащите в окно **содержимое** этой папки: `index.html`, папки `css`, `js`, `fonts` и остальные файлы.
   `index.html` должен лежать в корне репозитория, а не внутри вложенной папки.
4. Внизу нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В блоке *Build and deployment* выберите:
   - **Source:** Deploy from a branch
   - **Branch:** `main`, папка `/ (root)`
   - нажмите **Save**.
6. Через 1–2 минуты вверху страницы Pages появится ссылка на сайт. Её можно отправлять.

### Вариант Б. Через командную строку

В папке проекта выполните (подставьте свой логин и имя репозитория):

```bash
git init
git add .
git commit -m "Вітальна листівка"
git branch -M main
git remote add origin https://github.com/ЛОГИН/РЕПОЗИТОРИЙ.git
git push -u origin main
```

Затем выполните шаг 5 из варианта А (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).

### Обновления

Изменили файл, снова сделайте commit и push (или загрузите файл через сайт). GitHub Pages обновится примерно через минуту.
Если после обновления виден старый вид, обновите страницу с очисткой кэша (`Ctrl+F5`).

## Управление

| Действие | Как |
|---|---|
| Открыть | клик или тап по открытке, `Enter` |
| Листать вперёд | свайп справа налево (мышью можно потянуть), `→` `↓` `Space`, колесо вниз, загнутый уголок |
| Листать назад | свайп слева направо, `←` `↑`, колесо вверх |
| **Закрыть книгу** | свайп назад на **первой** странице или свайп вперёд на **последней** |

При закрытии открытка возвращается на стол, а при новом открытии стих пишется заново.
Если листнуть, пока текст ещё пишется, страница мгновенно дописывается.

## Что легко поменять

| Что | Где |
|---|---|
| Надпись на обложке | `index.html`, блоки `c-head` («З днем народження») и `c-name` («Оксана Анатоліївна») |
| Текст стиха | `js/poem.js`, страницы пересчитаются сами |
| Скорость письма | `SPEED`, `WORD_GAP`, `ROW_GAP`, `STANZA_GAP` в начале `js/writer.js` |
| Цвета | переменные `:root` в `css/base.css`, цвета цветка в `js/flower.js` |
| Заголовок вкладки | `<title>` в `index.html` |

Экран подстраивается сам: шрифт, поля, число страниц и масштаб пересчитываются на любом размере окна,
включая поворот телефона.

## Структура

```
index.html          обложка (надпись и рисунок) и подключение скриптов
css/base.css        палитра, фон, тень, подпись под открыткой
css/book.css        3D-книга, бумага, обложка, полосы изгиба
css/page.css        страница со стихом, «чернила», загнутый уголок
css/flower.css      анимация финального цветка
js/poem.js          текст стиха (строфы → строки)
js/layout.js        подбор шрифта под экран, перенос строк, разбивка на страницы
js/writer.js        «письмо»: проявление строк слева направо
js/book-core.js     размеры, камера, тень
js/book-open.js     открытие и закрытие книги
js/book-pages.js    DOM страниц, порядок листов, запуск письма
js/book-bend.js     изгиб листа при перелистывании
js/book-flip.js     жесты, клавиши, колесо, перелистывание, перемотка
js/flower.js        векторный цветок (строится кодом)
js/main.js          запуск, пересборка при изменении размера окна
fonts/              Marck Script (кириллица и латиница) и лицензия OFL
```
